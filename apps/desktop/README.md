# P8–P10：Slint V1 EEG 工作台与 LLM 报告

```bash
cargo run -p depression-desktop --offline
```

## 操作顺序

1. 点击“打开项目”，在系统弹窗中选择项目目录；应用会在目录内打开或初始化数据库。
   可在目录选择器中新建文件夹，之后通过“切换项目”打开其他项目。取消选择保留当前项目。
2. 在“受试者”页填写年龄/性别/备注，新建受试者；已有受试者通过顶部下拉框选择。
3. 在“导入设置”配置采样率、源振幅单位、CSV 表头、MAT 变量/方向，以及采集元信息。
   EDF 使用文件采样率和物理单位；CSV 每行一个时刻、每列一个通道；MAT 标签顺序须与矩阵一致。
4. 在“EEG 分析”页点击“选择 EEG 文件”，使用系统弹窗选择 EDF / CSV / MAT。
   格式按扩展名自动设置；文件名与路径只读展示。确认参数后点击“导入 EEG”。
   也可通过顶部录制下拉框加载已保存数据。
5. 独立点击“评价原始信号质量”，或配置 DC/带通/陷波/重采样，点击“运行完整分析”。
6. 图形区域默认勾选全部 EEG 通道。通过复选框、全选/全不选即时切换可见通道；
   波形和 PSD 同屏显示 8 个通道槽位，滚轮或右侧滚动条查看其余通道。选择区也可独立滚动。
   起点、窗长、±uV 量程修改后点击“更新显示”；上一/下一窗及时间放大/缩小可直接操作。
   通道集合变化滚动回首行，时间导航或量程改变保持当前通道滚动位置。
   地形图继续使用所有参与特征提取的导联，通道复选框只筛选波形和 PSD。
7. 在标签页浏览原始/处理后波形、PSD、Topomap、质量与频段功率。
   选择地形图频段和绝对/相对功率后点击“更新显示”。
8. 在“结构化结果”页查看参数、溯源、质量、频段功率与处理历史；可点击
   “保存处理后录制”保存独立派生录制。删除操作须先勾选确认；存在录制的受试者无法直接删除。
9. 完成分析后进入“报告”页，点击“生成报告”。先按 [LLM 配置说明](../../crates/llm/README.md)
   使用 `--features openai` 启动，配置 Key 和支持 JSON Schema 的模型。
   只在点击时发送脱敏的质量/频段事实；候选校验通过后才显示，失败可重试。

预处理默认 0.5–30 Hz 带通、50 Hz 陷波和去 DC；默认 Welch 为 2 秒 Hann 窗、50%
重叠、Delta/Theta/Alpha/Beta。采样率/Nyquist 或时长不足时显示错误，修改参数后重试。
质量谱分析默认检查 50 Hz 工频，可在导入设置中改为 60 Hz 或关闭；它与预处理陷波独立配置。
质量完整参数和特征参数由应用层公开的请求类型定义，
未来可进一步扩展 UI 设置。工程质量评分与地形展示只表达 EEG 结果，不给出抑郁诊断。

文件和目录都经系统弹窗选择。Linux 优先使用 Zenity，缺失时使用 KDialog；当前开发环境已有 Zenity。
Windows 使用 PowerShell STA + 原生 Forms 弹窗，macOS 使用系统 AppleScript 选择器；这两个平台的适配代码尚未实机验证。
弹窗只在独立线程等待，重复点击不会打开多个窗口；取消/失败/不支持的扩展名保留已有选择。
原始 `PathBuf` 保存在 Rust 中，界面字符串只用于展示，包含空格或非 UTF-8 字节的路径不会经 lossy 字符串重新构造。
所有磁盘操作、DSP、FFT、绘图准备在后台；
UI 解析表单、显示事件；独立 Rust 像素后端把准备好的 DTO 直接绘制到
`SharedPixelBuffer<Rgba8Pixel>`，通过 `Image::from_rgba8` 显示，不再生成/解析 SVG。
每条曲线对应独立像素图与通道行，原始样本、PSD 数值和地形网格不被绘图改变。
通道名、坐标、电极与色标标签使用原生 Slint Text 保持清晰字号；地形图保留透明掩码与固定色标。
像素缓冲按实际视区大小 × 屏幕 DPI × 2 倍超采样创建，窗口放大和屏幕缩放变化自动重绘。
线宽同样按逻辑像素换算，避免高 DPI 或缩小显示时曲线变细。地形图使用 256×256
展示网格和双线性显示采样。桌面默认采用 `HeadCircle` 覆盖，在整个头圆内做 IDW
展示插值，圆外透明；边缘只对有效邻格归一化采样，避免圆边留下透明缝。
展示扩展不改变分析特征、电极原值和固定色标；P7 的 `ElectrodeHull` 策略仍可保留凸包外透明区域。
波形包络最多保留每通道 8192 点，同时受 P7 总点数预算约束；PSD 不改变 Welch 频点。
布局更新由 UI timer 合并，仅重绘图像；相同 DTO/尺寸复用像素缓存，滚轮不触发重绘或分析。
大量通道和超大窗口有统一分配预算：所有波形/PSD 当前缓冲合计约 128 MiB 上限，
地形图缓冲最多 8M 像素；超出预算时同比例降低超采样，避免无限分配。
处理期间禁用重复提交，错误以界面文本展示。

P9 已接入 Provider、脱敏投影、受控语言 Narrative 校验和报告页。默认构建保留离线 EEG 功能，
未启用/配置 Provider 时报告生成明确提示错误。P10 已接入 PDF / DOCX / JSON / CSV 导出。
分析结果保存在会话内存，原始和显式保存的派生样本持久化；重启后可加载录制并重新分析。

## 源码

- `ui/app.slint`：页面、输入、系统选择按钮、图形与状态显示。
- `ui/theme.slint`：共享中性色、字号、8px 间距尺度、白色面板和主操作组件。
- `src/file_dialog.rs`：可注入的原生选择器接口、后台弹窗调度、取消/错误/路径协议处理。
- `src/app.rs`：生命周期、回调→命令映射、非阻塞事件消费。
- `src/presentation.rs`：快照→文本/复选框模型/逐通道图像；旧结果清理与滚动位置恢复。
- `src/raster.rs`：Rust 直接绘制 SharedPixelBuffer，有限线宽抗锯齿、精确裁剪、单点与地形采样。
- `src/render_size.rs`：独立的视区/DPI 像素尺寸与内存预算计算。
- `src/plot_renderer.rs`：接收布局回报、合并更新、按 DTO 与物理尺寸缓存像素。
- `ui/plots.slint`：8 行滚动视区、地形图原生文本叠层、布局尺寸回报。
- `../../crates/eeg-application`：独立、无 Slint 的应用服务与调度。

默认构建复用已有 Slint、serde_json 和 P2–P7 包；`openai` 功能启用可选的 async-openai/Tokio 依赖。
Linux 运行时需要系统已有的 Zenity 或 KDialog。
界面固定使用浅色 Fluent 组件：浅灰画布、白色面板、细分割线、清晰字号与蓝色主操作；普通面板不加阴影。
参考 [Slint 官方组件样式文档](https://docs.slint.dev/latest/docs/slint/reference/std-widgets/style/)。

## 测试

```bash
cargo test -p eeg-application -p depression-desktop --offline
cargo clippy -p eeg-application -p depression-desktop --all-targets --offline -- -D warnings
cargo fmt --all -- --check
```

`tests/ui_smoke.rs` 使用 Slint 自带的软件窗口平台，实际调用界面回调完成
系统选择回调（注入选择器）、创建项目/受试者、取消/失败/非法扩展名恢复、CSV 导入、
质量、预处理/重采样、特征/图形、导航、保存、错误恢复，
并使用 12 通道数据验证默认全选、全不选/单选、真实滚轮事件与图像变化、滚动位置保持/重置，
验证窗口放大、2× 屏幕 DPI 的真实缓冲增长、缓存复用和分析/显示参数保持，
验证报告生成、超时保留旧文档和重试，再渲染五个主页面和五个结果标签。
不依赖显示服务器，不调用真实 LLM API。
`tests/file_dialog.rs` 验证弹窗等待不阻塞、重复请求保护和取消/错误后的重试；
模块单元测试检查平台命令参数、扩展名识别、原始路径字节及取消与失败的区分。
`raster` 模块单元测试检查超量程线段的真实裁剪、单采样点、幅度缩放、常量 PSD、
非法坐标、DPI 下逻辑线宽一致、地形图双线性插值/透明掩码/固定色标。
尺寸单元测试覆盖整数/小数 DPI、非法几何和大量通道/超大视区的预算限制。应用层测试检查超过 8 通道的默认显示，
以及 `None`（默认全选）和 `Some([])`（全不选）不会混淆、显示调整复用分析结果。
这些自动测试不会实际操作 OS 弹窗。

可选择输出合成测试的页面 PPM 图像以进行视觉检查：

```bash
P8_UI_PREVIEW_DIR=/tmp/p8-preview cargo test -p depression-desktop --test ui_smoke --offline
```

## P10 文件导出

完成分析后进入“报告”页，选择格式并点击“导出文件”，在系统保存弹窗选择
目录和文件名。JSON / CSV 无需调用 LLM；PDF / DOCX 使用当前已校验报告，
同时包含采集信息、导联序号映射、质量/频段功率和处理溯源附录。
导出完成显示实际路径与字节数。取消、选择错误扩展名或写入失败可以重试，
已有文件不会被覆盖，请选择新的文件名。弹窗和文件编码均在后台线程运行。

PDF 需要支持中文的可嵌入 TrueType `.ttf`；自动检测失败时设置
`EEG_REPORT_FONT=/path/to/font.ttf`。字体要求、归档字段和科研 CSV 读取合同详见
[report/README.md](../../crates/report/README.md)。本次无需新增 Cargo 依赖。

Linux 保存弹窗使用 Zenity `--save` / KDialog `--getsavefilename`；Windows 使用
SaveFileDialog；macOS 使用 choose file name。Windows/macOS 尚未实机验证。
`ui_smoke` 现已通过真实 Slint 回调验证离线 JSON / CSV 导出、重复弹窗门控、
取消、保存器失败、扩展名错误、已有目标拒绝，以及 DOCX 重试成功且正文保持。
